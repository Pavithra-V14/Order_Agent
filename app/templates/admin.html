Admin — Data Management

Development/testing reset tools. These delete real data with no undo — used mainly to reset the system to a clean state between test runs.

Delete Audit Log

Deletes every audit log entry only. Cases, orders, and everything else stay untouched.

Delete RAG Index

Deletes the Qdrant collection (policy embeddings) and clears the local reindex-state tracker. Run scripts/run_ingestion.py afterward to rebuild it from scratch.

Delete ALL Data (Postgres/SQLite)

Every case, order, stock record, audit entry, trace span, learning-loop pattern, and threshold override — gone. Does not touch the RAG index or the long-term memory graph (Neo4j/Kuzu) — those have their own separate reset above / are external systems.
