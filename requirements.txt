# =============================================================================
# All-cloud, no-Docker production stack. Every external dependency below has
# a REAL implementation (not a stub) that activates automatically once its
# credential is set in .env — see .env.example for signup links to each
# service's free tier. Leave any credential unset and the corresponding
# local-first fallback (SQLite / in-process cache+queue / embedded Qdrant /
# TF-IDF embeddings / rule-based fake LLM) is used instead — nothing crashes
# on a partial configuration, and Docker is never required anywhere in this
# stack, in either mode.
# =============================================================================

# app/workers/job_queue.py (RQJobQueue) from the SAME Redis instance.

# ── LLM — Groq (cloud, no Docker) ───────────────────────────────────────────
# GroqClient (app/agents/llm_client.py) auto-activates when GROQ_API_KEY is
# set, falling back to the rule-based FakeLLMClient otherwise. Real httpx
# calls against Groq's OpenAI-compatible chat completions API, tested
# against realistic mocked responses (tests/test_groq_client.py).

# ── Embeddings — Mistral (cloud, no Docker) ─────────────────────────────────
# MistralEmbedder (app/rag/embeddings.py) auto-activates when
# MISTRAL_API_KEY is set, falling back to local TF-IDF otherwise. Tested
# against realistic mocked responses (tests/test_mistral_embedder.py).
# NOTE: switching embedding backends after documents are already indexed
# requires re-ingesting into a NEW Qdrant collection (embedding dimensions
# differ: TF-IDF=768, Mistral=1024) — see README for the migration note.

# ── Carrier — EasyPost (cloud, no Docker) ───────────────────────────────────
# EasyPostGateway (app/tools/carrier.py) auto-activates when
# EASYPOST_API_KEY is set, falling back to FakeCarrierGateway otherwise.
# Implemented as raw httpx calls against EasyPost's REST API directly
# (NOT the `easypost` SDK package — that SDK uses `requests` internally,
# which this project's respx-based test strategy can't intercept; a
# "mocked" SDK-based test was confirmed to silently hit the real network
# instead during development). Tested against realistic mocked responses
# (tests/test_easypost_gateway.py).
#
# NOTE: EasyPost's 2026 onboarding now gates API key access behind adding
# a payment method to your account first (a real, discovered-in-practice
# change from the "no card needed" behavior their older docs describe).
# If that's not something you want to do, ShippoGateway (below) is a
# ready-to-use alternative requiring only a direct goshippo.com signup.

# ── Carrier alternative — Shippo (cloud, no Docker) ─────────────────────────
# ShippoGateway (app/tools/carrier.py) auto-activates when SHIPPO_API_KEY
# is set — EasyPost takes priority if BOTH are configured (pick one in
# practice, see get_carrier_gateway()). Same raw-httpx pattern as
# EasyPostGateway, using Shippo's real REST API (ShippoToken auth scheme,
# confirmed from their docs, not assumed). Tested against realistic
# mocked responses (tests/test_shippo_gateway.py), including a dedicated
# test proving the lowest-cost rate is actually selected, not just the
# first one returned.
