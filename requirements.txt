# a REAL implementation (not a stub) that activates automatically once its
# credential is set in .env — see .env.example for signup links to each

# stack, in either mode.

# ── LLM — Groq via a real gateway (LiteLLM), cloud, no Docker ──────────────
# LiteLLMClient (app/agents/llm_client.py) auto-activates when GROQ_API_KEY
# is set, falling back to the rule-based FakeLLMClient otherwise — the real
# LLM gateway: routes through litellm.Router rather than calling Groq's API
# directly (GroqClient, kept in this file for its own well-tested request/
# response handling, but no longer what get_llm_client() actually returns).
# Adds three real, verified capabilities: genuine exponential backoff with
# jitter (litellm's own _calculate_retry_after, checked directly against
# source), per-deployment rate limiting (rpm), and a cooldown mechanism
# (allowed_fails/cooldown_time) - on top of this project's OWN
# CircuitBreaker wrapping the whole thing, so an LLM outage is observable
# the same way every other dependency's outage is (the same
# circuit_breaker_trip alert, the same /admin/alerts visibility), not a
# separate, unmonitored subsystem. Tested against realistic mocked
# responses (tests/test_litellm_client.py), including a dedicated test
# proving the project's own breaker genuinely trips on sustained failures,
# not just litellm's internal cooldown.
litellm>=1.50
